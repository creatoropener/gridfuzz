# GridFuzz: implementation plan

Each task lists the requirements it satisfies (see [requirements.md](requirements.md)). Checked tasks are implemented and covered by the tests named in the task; unchecked tasks are open.

- [x] 1. Project foundation
  - Vite + React + strict TypeScript, Vitest, Playwright, GPL-3.0-only licence, static build.
  - _Requirements: R7.4, R10.1_

- [x] 2. Workbook model and import
  - [x] 2.1 `WorkbookModel`, A1 helpers, `CellEdit`, immutable `applyEdits` (`tests/workbook.test.ts`)
    - _Requirements: R5.1, R5.4_
  - [x] 2.2 SheetJS adapter (the only SheetJS import) with `sheetStubs: true` so formula cells without cached values survive
    - _Requirements: R1.6_
  - [x] 2.3 Upload validation: type, 5 MB size, 200,000 cell limit, corrupt-file errors, CSV with BOM
    - _Requirements: R1.1, R1.2, R1.3_
  - [x] 2.4 Sheet selection and preview with formulas, values and dependencies
    - _Requirements: R1.4, R1.5_

- [x] 3. Calculation engine
  - [x] 3.1 `CalcEngine` over HyperFormula, one private instance per run, error values as data (`tests/workbook.test.ts`)
    - _Requirements: R3.1, R3.2, R3.6_
  - [x] 3.2 Precedents and dependents (range vertices resolved to reading formulas, de-duplicated)
    - _Requirements: R1.5, R4.4_
  - [x] 3.3 Formula analysis: unsupported functions, volatile functions, baseline errors
    - _Requirements: R10.2_

- [x] 4. Rules
  - [x] 4.1 Zod `RuleSchema` for six rule types, `TestConfigSchema` (`tests/schema.test.ts`)
    - _Requirements: R2.4, R2.7_
  - [x] 4.2 Safe expression parser and evaluator, no `eval` (`tests/expression.test.ts`)
    - _Requirements: R2.8_
  - [x] 4.3 `RuleCompiler` interface and `LocalRuleCompiler` with ten documented patterns, cell resolver, refusal of unsupported sentences (`tests/rule-compiler.test.ts`)
    - _Requirements: R2.1, R2.2, R2.3, R2.9_
  - [x] 4.4 `RuleDraft` to `Rule` validation
    - _Requirements: R2.6, R2.7_

- [x] 5. Property engine
  - [x] 5.1 Scaled-integer generators anchored at the current cell value (`tests/generators.test.ts`)
    - _Requirements: R3.1, R4.1_
  - [x] 5.2 Property definitions: monotonic, bounds, non-negative, invariant, conditional (`tests/properties.test.ts`)
    - _Requirements: R2.4, R3.6, R3.7, R3.8_
  - [x] 5.3 Generic runner: census pass, seeded shrink pass, input restoration and leak detection
    - _Requirements: R3.2, R3.3, R4.1, R4.2_
  - [x] 5.4 Explanations: confirmed and suggested findings, highlight sets
    - _Requirements: R4.3, R4.4, R4.5, R10.3_
  - [x] 5.5 `runRule` entry point and `scenarioView` (counterexample applied to a copy)
    - _Requirements: R4.5_

- [x] 6. Worker and run control
  - One worker per run, progress messages, cancel via `terminate()`, error states.
  - _Requirements: R3.1, R3.5, R3.9_

  - [x] 7.1 Workbook with the rebate-threshold bug, generated by `scripts/generate-samples.mjs` (`public/samples/freight-quote.{xlsx,csv}`)
    - _Requirements: R7.1, R7.4_
  - [x] 7.2 Four sample rules; flagship rule finds and shrinks the bug, the fix passes with the same seed (`tests/freight-demo.test.ts`)
    - _Requirements: R7.2, R7.3_

- [x] 8. Services and state

  - [x] 8.2 `useAppState` and `AppContext`: import flow, session, edits, runs, tab routing after a run, export, clear data
